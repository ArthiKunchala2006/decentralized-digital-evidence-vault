# decentralized-digital-evidence-vault
Secure decentralized digital evidence storage and verification system using cryptographic hashing, QR codes, and blockchain-inspired architecture.
Decentralized Digital Evidence Vault

Project Overview

The Decentralized Digital Evidence Vault is a blockchain-inspired platform that allows users to securely upload digital evidence and verify its authenticity using cryptographic hashing and transaction IDs.

Features

- Secure file upload
- SHA-256 hash generation
- Transaction ID creation
- QR code generation
- Evidence verification
- Tamper detection
- Blockchain-style storage simulation

Tech Stack

Frontend:

- HTML
- CSS
- JavaScript

Backend:

- Python
- Flask

Libraries:

- hashlib
- qrcode
- Pillow

Project Structure

frontend/
index.html

backend/
app.py
requirements.txt

How to Run

1. Install dependencies
   pip install -r requirements.txt

2. Run backend
   python app.py

3. Open frontend/index.html in browser

How It Works

1. User uploads file
2. System generates hash
3. Transaction ID created
4. QR code generated
5. File stored securely
6. Later user verifies using txid

Conclusion

This project demonstrates secure digital evidence storage using blockchain-inspired verification techniques.
